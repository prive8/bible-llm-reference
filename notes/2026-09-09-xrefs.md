# 2026-09-09 — Milestone 4 (cross-reference engine) shipped + docs sweep

## Done

- **Milestone 4 — openbible.info cross-references integrated.** Ingested
  344,800 raw edges (CC-BY 4.0) into `data/references/cross_references.json`
  (19 MB, 605,043 edges after range expansion across 29,336 source verses).
  Raw TSV also committed for auditability.
- **`bible/references.py`** — pure stdlib, three public functions:
  - `get_references(ref)` — outgoing edges, sorted by votes desc
  - `get_reciprocal(ref)` — incoming edges (verses that point AT this one),
    built lazily once via an inverted index
  - `traverse(ref, hops=2)` — multi-hop expansion, cycle-safe, clamped to
    1–3 hops (beyond 3 the result set becomes noise rather than signal)
- **CLI subcommand:** `python -m bible references "John 3:16" [--hops N]
  [--min-votes V] [--direction out|in|both] [--json]`. Wired into
  `bible/__main__.py`.
- **13 new sister-script tests** — suite now at **39 passing tests**.
  Smoke tests assert John 3:16's top edge is Romans 5:8 (871 votes) and
  Genesis 1:1's top hop-2 edge is John 1:1 (304 votes).
- **`data/references/README.md`** — license provenance, schema, refresh
  instructions.
- **`scripts/ingest_cross_references.py`** — one-shot ingestion script.
  Idempotent; safe to re-run.
- **ADR-008** in `docs/design-decisions.md` — openbible.info as the
  Phase 1 cross-reference substrate, with rationale and Phase 3
  implications.
- **CHANGELOG v0.4.0**, **HANDOFF §5** (M4 done), **HANDOFF §8**
  (pending-decisions list refreshed), **docs/design-decisions.md**
  pending list updated.

## Blocked

## Tomorrow / Next decisions

- **Milestone 3B (Dense embeddings / Semantic search).** Same as the
  previous note — local `sentence-transformers/all-MiniLM-L6-v2` (~80MB,
  optional dep) vs. hosted NVIDIA NIM. ADR-009 is the next thing to
  draft when this is unblocked. **Not shipped today** — the cross-ref
  engine materially reduces the urgency of semantic search, because
  cross-refs answer the "what other verses are related to this" question
  without any model at all.
- **Phase 3 cross-tradition ingestion.** ADR-008 flags the gap: non-
  Christian traditions need their own cross-reference sources (Quran
  tafsir cross-refs, rabbinic Tanakh cross-refs, etc.). Not started.
- **`bible-query.py` removal.** Still pending per yesterday's note. The
  `bible search` command is fully functional and tested.
