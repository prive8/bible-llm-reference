# 2026-09-09 — Bug fix + Milestone 5 skeleton + tests

## Done

- **Fixed the `--strongs` regression in `bible-query.py`.** It was inlining lemma + gloss into the English text, producing unreadable output (e.g. `Forבִּכּוּרָה…Godחֲדַר…`). Now strips the `<S>N</S>` tags from the English line and prints the Strong's references as a separate, formatted block below.
- **Real parser bug squashed:** `bible/lookup.py::resolve_book_name` had a fuzzy substring fallback that resolved `1jn 4:8` to `John 4:8` instead of `1 John 4:8`. Replaced with exact alias + canonical-name match. Added `1jn`/`2jn`/`3jn` no-space aliases to the alias map.
- **20-test sister-script suite landed** at `tests/run_all.py`. Stdlib-only, no pytest. Covers: reference parser (7 tests), KJV loading (3), Strong's linkage (3), translation enumeration (2), parallel lookup (2), Strong's CLI (2), and a regression test for the `--strongs` bug above. All 20 pass.
- **Milestone 5 docs skeleton:** `docs/design-decisions.md` (6 ADRs — stdlib-only, multi-tradition constraint, Strong's-as-JS, legacy CLI deprecation, sister-script tests, fuzzy-match removal) and `docs/evaluation.md` (shell with what we measure at each milestone + explicit non-goals).
- **CHANGELOG bumped to v0.2.0** with the additions/changes/fixes/deprecations above.
- **`pyproject.toml` entrypoint fixed.** Was pointing at a non-existent `bible_query:main`; now points at `bible.__main__:main` so `pip install -e .` actually exposes the `bible` command.
- **HANDOFF.md §5 status updated** to mark Milestones 1 and 2 done and reflect the live test suite as the Milestone 5 deliverable.
