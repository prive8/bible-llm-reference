# Cross-Reference Data

This directory contains the openbible.info Bible cross-reference dataset,
used by `bible/references.py` and the `python -m bible references` CLI.

## Files

- `cross_references.txt` — raw TSV, downloaded from openbible.info. **8 MB,
  344,800 lines.** Source-of-truth.
- `cross_references.json` — normalized, canonical-book-keyed JSON. **~19 MB.**
  Generated by `scripts/ingest_cross_references.py`; safe to commit.

## Schema

After ingestion, the JSON shape is:

```json
{
  "metadata": {
    "source": "openbible.info cross-references",
    "license": "CC-BY 4.0",
    "edges_kept": 605043,
    "outgoing_keys": 29336
  },
  "outgoing": {
    "John 3:16": [
      {"to": "Romans 5:8", "votes": 871},
      {"to": "1 John 4:9", "votes": 618},
      ...
    ],
    ...
  }
}
```

Edges with negative votes were filtered at ingest time (1,166 of 344,800
raw rows). Self-loops are filtered at ingest time. Multi-verse ranges in
the raw data (e.g. `Prov.8.22-Prov.8.30`) are expanded into individual
verse edges.

## How to refresh

```bash
curl -L -o data/references/cross_references.txt \
  https://raw.githubusercontent.com/scrollmapper/bible_databases/master/sources/extras/cross_references.txt
python3 scripts/ingest_cross_references.py
```

Both files are then ready to commit.
