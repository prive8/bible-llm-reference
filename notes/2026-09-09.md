# 2026-09-09 — Bug fix + Milestone 5 skeleton + Milestone 3A (BM25 search) + CI

## Done

- **Fixed cross-platform Windows UTF-8 console crash (`UnicodeEncodeError`).** Windows console defaults to cp1252, which failed on checkmarks (`✓`) and Hebrew/Greek characters. Reconfigured `sys.stdout`/`sys.stderr` with UTF-8 and fallback replacement in `tests/run_all.py`, `bible/__main__.py`, and `bible-query.py`.
- **Milestone 3A — Pure-stdlib Okapi BM25 search engine landed:**
  - Implemented `bible/search.py` using standard library only (`math`, `re`, `unicodedata`, `collections`).
  - Multilingual & ancient-text tokenization: handles Latin, Hebrew, Greek, Cyrillic, Arabic, and individual CJK character segmentation.
  - Diacritic-insensitive normalization (`NFKD` mark stripping) so unpointed Hebrew (`ברא`) or unaccented Greek matches pointed/accented original texts (e.g. WLCa, LXX).
  - Phrase boost and coverage multiplier: exact consecutive phrases like `"faith without works"` rank James 2:20 and 2:26 at the top.
  - Translation-pluggable: searches KJV by default or any translation (`-t WEB`, `-t YLT`, `-t WLCa`, etc.).
  - CLI: `python -m bible search "..." [-t WEB] [-n 10] [--strongs] [--json]`.
- **GitHub Actions CI workflow landed:** `.github/workflows/ci.yml` running the 25-test suite across Ubuntu and Windows on Python 3.10–3.13.
- **Sister-script suite expanded to 25 tests:** Added `t_search_faith_without_works`, `t_search_no_results`, `t_search_translation_web`, `t_search_cli_json`, and `t_search_multilingual_wlca_hebrew`. All 25 pass cleanly on Windows and Linux.
- **ADR-007 documented:** In `docs/design-decisions.md` (Stdlib Okapi BM25 as Canonical Search Baseline).
- **Evaluation doc updated:** In `docs/evaluation.md` with active BM25 evaluation benchmark targets.
- **README & pyproject.toml updated:** Bumped package to `0.3.0`, updated Quick Start with search commands.
